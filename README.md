# Villa Permai

Halaman pemesanan vila statis untuk tugas UTS Teknologi Web. Aplikasi dibuat tanpa back-end, framework, maupun library eksternal.

## Menjalankan aplikasi

1. Unduh atau klon repository ini.
2. Buka `index.html` di peramban.

Tidak diperlukan instalasi paket atau server khusus.

## Fitur

- Navigasi bagian Pilihan Vila, Pemesanan, dan Kontak melalui hash URL.
- Pencarian vila berdasarkan nama, lokasi, tipe kamar, dan fasilitas.
- Perkiraan harga otomatis berdasarkan harga per malam dan jumlah malam.
- Validasi data pemesanan dan pemeriksaan bentrok jadwal.
- Penyimpanan nama tamu terakhir dan pesanan di `localStorage` peramban.
- Tata letak responsif untuk layar desktop dan ponsel.

## Berkas

- `index.html` — struktur dan konten halaman.
- `style.css` — tampilan dan tata letak responsif.
- `script.js` — data vila, navigasi, kalkulasi, validasi, serta penyimpanan pesanan.

## Catatan

Data pesanan hanya tersimpan di peramban yang digunakan dan tidak dikirim ke pemilik vila. Nomor WhatsApp pada halaman merupakan kontak yang dicantumkan untuk proyek ini.
